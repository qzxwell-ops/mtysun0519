## Daily Workflow

1. Add or update products.
2. Upload product images with accurate alt text.
3. Add SEO title and description before publishing.
4. Review inquiry messages every business day.
5. Publish at least three content updates per week.

## Product Publishing Rules

Each product should include:

- Clear English product name
- Category
- OEM number
- Vehicle application
- Short description
- Packaging options
- At least three product images
- Downloadable catalog or specification file
- SEO title
- SEO description

## News Publishing Rules

Each article should include:

- Buyer-oriented title
- Short excerpt
- Real product or factory image
- Internal links to products
- Inquiry call to action
- SEO title under 60 characters
- SEO description under 155 characters

## Inquiry Handling

Recommended stages:

- New
- Assigned
- Quoted
- Sample requested
- Follow-up
- Won
- Lost

Each inquiry should store source page, market, product interest and follow-up notes.
